## Controls
### windows+cntrl+J
duck goes crazy and changes colours

### winows+cntrl+K
duck goes bye bye

### windows+cntrl+T
duck goes into focus mode for 25 minutes

### click the duck
it will switch out of flying mode, click it again to make it fly! also makes a quacking noise

## How it works

I used Godot Game Engine to make this project, coded in GDscript and assets from Itch.io!
